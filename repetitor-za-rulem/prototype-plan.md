# Web-прототип — 5 бесплатных фраз

Статус: реализованный первый прототип.

Источник: первые 5 фраз из `content/lesson-1-final-core.md` и сценарий `content/lesson-1-handsfree-script.md`.

## Цель

Не делать курс заранее. Дать человеку бесплатно физически попробовать формат:

`Начать -> голосовой вопрос -> микрофон ждёт -> ответ или команда -> следующая фраза -> вопрос "нравится?"`

Если человеку нравится, тогда отдельно делается полный урок. Оплата появляется только после полного урока и отдельного решения Рихарда, не в этом прототипе.

## Что входит

| Часть | Что делает |
|---|---|
| Старт | одна кнопка `Начать` |
| Урок | показывает текущую латышскую фразу крупно |
| Озвучка | готовые MP3 через Google TTS |
| Микрофон | после старта пытается слушать постоянно |
| Команды | `atkārto`, `turpinām`, `stop/pauze`, `tālāk` |
| Проверка | мягко сравнивает голосовой ответ с ожидаемой латышской фразой |
| Закрепление | после первых 5 фраз предлагает `jā` и даёт 10 перестановок из кирпичиков |
| Финал | показывает результат пробного урока или закрепления |

## Что не входит

- Оплата.
- Аккаунты.
- Пульт Рихарда.
- Supabase / Firestore.
- Персонализация.
- Полный урок на 26 фраз.
- Финальная проверка 10 фраз.

## Продуктовая логика

1. Человек пробует 5 фраз бесплатно.
2. Если формат понравился, Рихард может дать полный урок.
3. После полного урока человек даёт обратную связь.
4. Только потом человек переводится в отдельную оплатную часть, если сам хочет продолжать.

## Техническая логика

Страница использует:

- готовые MP3 из `web-tutor/audio/` для голоса репетитора и латышских подсказок;
- `SpeechRecognition` / `webkitSpeechRecognition` для микрофона.

Важно: настоящий постоянный микрофон зависит от браузера и телефона. Прототип проверяет, насколько близко web-режим может подойти к ощущению Copilot.

## Первый тест

Открыть страницу на телефоне или в браузере:

1. Нажать `Начать`.
2. Разрешить микрофон.
3. Ответить: `es gribētu to izdarīt`.
4. Проверить команды: `atkārto`, `turpinām`, `tālāk`, `stop`.
5. После 5 фраз сказать `jā` и пройти закрепление из кирпичиков.
